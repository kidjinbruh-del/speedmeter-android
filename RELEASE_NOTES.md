# Спидометр 1.0.0

Первая версия: измерение скорости интернета на телефоне.

## Что измеряет

| Метрика | Как считается |
|---------|---------------|
| Загрузка | Файл с открытого эндпоинта Cloudflare, размер растёт лесенкой (1 → 2 → 4 → … МБ), скорость — по фактически прочитанным байтам |
| Отдача | Отправка случайных байт на тот же эндпоинт |
| Задержка | Время до первого байта ответа (TTFB), восемь попыток |
| Джиттер | Средняя разница между соседними замерами задержки |

## Почему результату можно верить

Наивный замер врёт в трёх местах, и здесь каждое закрыто:

- **Размер файла растёт лесенкой.** Маленький файл измеряет скорость
  установления соединения и показывает 200 Мбит/с там, где канал 20.
- **Первые четверть потока не учитываются.** Это разгон TCP и заголовки
  ответа.
- **Скорость считается по фактическим байтам**, а не по `Content-Length`:
  обрыв на середине иначе дал бы фантастические мегабиты.
- **Медленнейший замер выбрасывается**, остальное сводится медианой.
- **`Accept-Encoding: identity`**: иначе мы считали бы сжатый объём вместо
  реального трафика.

## Что нашли и починили на телефоне

- **Задержка показывала 961 мс.** Первый запрос платит за DNS, TCP и TLS;
  раньше эта секунда попадала в результат. Добавлен прогрев перед серией
  и отбрасывание первого настоящего замера — стало 89 мс.
- **Пустой ответ считался «нет данных»**, и задержка показывала ноль.
  Теперь замер засчитывается по успешному ответу, тело значения не имеет.
- **Стрелка перечёркивала число** на датчике — теперь она рисуется во
  внешнем поясе.
- **Джиттер показывал 684 мс** при задержке 204 мс. Причина не в сети:
  среднее по разницам между соседними замерами переписывала одна заминка.
  Теперь самая долгая запись убирается, и джиттер показывает разброс
  канала, а не единичное ожидание.
- **Кнопка «Измерить» не находилась поиском по надписи**: текст начинался
  с двух пробелов — «  Измерить». Отступ теперь задаётся рядом, а не
  пробелами в строке.
- **Три чипа длительности пропали из настроек**: каждая наклейка тянулась
  на всю ширину, и в ряд помещался только первый.
- **Заголовок уезжал под статус-бар** — добавлены отступы системных полос.

## Проверки

- 28 модульных тестов: перевод байтов в мегабиты, медиана против выброса,
  джиттер, отбрасывание заминки, процентили, лесенка размеров, сборка
  адресов замера.
- Тест на «медленный первый замер не тянет итог вниз» — сделан после того,
  как приложение показало 12 Мбит/с на канале за 80.
- Тест на заминку — сделан после того, как джиттер показал 684 мс при
  задержке 204 мс.
- Прогон вёрстки по семи профилям экрана (`device-lab layout.ps1`): 14
  проверок без замечаний.

## Честные границы

- Замер идёт до чужого сервера, поэтому результат зависит от маршрута.
  Для сравнения «сколько у меня в тарифе» годится, для точной диагностики
  канала — нет.
- Отдача на мобильном интернете часто ограничена сетью оператора.

## Данные

Разрешений ровно два: `INTERNET` и `ACCESS_NETWORK_STATE`. Никаких
аккаунтов, рекламы и аналитики; история замеров лежит только на
устройстве.
